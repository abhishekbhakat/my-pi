# Global agent instructions

## Pi documentation

Only when the user asks about Pi itself, the SDK, extensions, themes, skills, or the TUI: read the relevant docs before implementing. The install is bun global. Base: `~/.bun/install/global/node_modules/@earendil-works/pi-coding-agent/` (`README.md`, `docs/`, `examples/`). Binary: `~/.bun/bin/pi`. Not Homebrew npm.

`~` resolves per machine and per user. This layout exists on any machine installed via `make install` or the my-pi bootstrap binary.
