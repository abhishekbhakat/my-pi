5 · Write the testsThe verifier runs after the agent finishes, in a fresh container from the task's single image (environment/Dockerfile — the single-Dockerfile rule and allowlist live on Step 6); tests/ is added only at verify time and is not present during the agent run. The verifier can read only: the output files the agent wrote at the /app/... paths your instruction.md declares, anything baked into the single image, and sidecars from environment/docker-compose.yaml.
